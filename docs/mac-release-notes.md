Download the complete Mac app. There is no source build or dependency installation on the recipient’s Mac.

- **Install-Classroom-Copilot.zip:** unzip, then double-click Install Classroom Copilot.command. It selects Apple Silicon or Intel, checks the download, installs the app, and opens it.
- **Classroom-Copilot-mac-arm64.zip:** full Apple Silicon app.
- **Classroom-Copilot-mac-x64.zip:** full Intel app.
- Matching `.sha256` files verify the app downloads.

Includes the native Codex runtime, first-run setup, course-folder transcript saving,
and Stop-confirmed notes using GPT-6.1 Sol with low reasoning. Notes review every
same-profile/day speech recording, combine related Start/Stop fragments and keep
unrelated topics distinct. The confirmation, progress and saved popups share the
app’s styled interface.

Bring your own sign-in and provider keys. Publisher credentials, OMP auth stores,
private settings and recordings are excluded. Updates preserve user data and refuse
to replace a running recording app.

This release is ad-hoc signed and not notarized. macOS may require first-open review
in System Settings → Privacy & Security. The installer does not disable Gatekeeper
or remove quarantine. Developer ID signing/notarization remains future work.
